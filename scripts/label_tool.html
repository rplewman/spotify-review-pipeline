Our rules (labels/taxonomy.md §2)
  • Paid-plan mention alone ≠ billing; crashing for a paying user = playback; subscription not activating = billing.
  • Premium-only controls (skips, choosing songs, repeat, seeking) → billing, usually severity 3.
  • Ads → usability, usually 2. Connection errors / audio quality → playback.
  • Boycott slogan → unclear / other / 1. Explicit "I uninstalled" → cancellation, still severity of the actual problem.
  • Cancellation never raises severity. Mixed praise + criticism → complaint.
  • Positive review → first specific praised feature; general praise → other.
  • Sentiment: −1 hostile · −0.5 negative · 0 neutral/balanced · +0.5 positive · +1 enthusiastic.
  • Tick an alternative only if a second reading is genuinely defensible.
