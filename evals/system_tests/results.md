# M7 system tests

Generated by `scripts/system_tests.py`. Each scenario runs on its own synthetic DB (SYNTH- IDs under `state/m7_system/`), never on `state/pipeline.db`. Full details in `results.json`.

| Scenario | Result | Expected |
|---|---|---|
| Planted error (verifier) (`planted_error_verifier`) | PASS | 5 wrong topics planted in a separate copy of the first labels are all flagged by the independent verifier's comparison; the real records are untouched |
| Planted error (checks) (`planted_error_checks`) | PASS | each planted contract violation in a test copy is rejected by pipeline.schema.validate_record; a resume call re-sending a checkpointed ID is flagged by the resume rules |
| Prompt injection (a model that obeys) (`injection_fake`) | PASS | an invalid label never reaches a record (enum check); a review whose output is invalid twice is quarantined with its reason; an answer for an unsent review is rejected (whole call unusable → bisected until the culprit is alone); quotes are cut by code, never taken from the model; the other reviews complete |
| Injection in A9/A11 (`group_memo_injection`) | PASS | the invented issue name is dropped; the memo with an unknown issue/review ID and an unsupported number fails the code check, is retried once with the errors, and only the clean answer is written |
| Malformed output (`malformed_output`) | PASS | a non-JSON response fails the call, which is bisected and re-sent (no review charged an invalid attempt for it); a review missing from the answer twice is quarantined with reason and attempt count in outputs/quarantine.jsonl; every other review completes |
| Missing text (`missing_text`) | PASS | empty / whitespace-only texts are quarantined at intake with reason 'empty_review_text' and never sent to a model; the rest complete |
| Ambiguous label (`ambiguous_label`) | PASS | low-confidence (ambiguous) reviews still get one valid label; every probability is saved with the decision (agent_outputs A3); under the frozen config only severity is escalated, so a low topic probability does not by itself set needs_review (known limitation, golden recall 15%) |
| Temporary API failure (`transient_failures`) | PASS | 429 / 408 are retried with backoff (429 not charged, 408 settled at the estimate) and the queue drains; 402 stops everything with no lease left and resume finishes; 400 stops the run; an item failing 3 times (max_attempts) is marked failed, not retried forever |
| Spend controls (`spend_controls`) | PASS | the ledger reserves before every call and stops admitting work before the cap (spent ≤ cap, nothing left reserved); a paid provider without --paid/--max-spend is refused; a fake run on state/pipeline.db is refused |
| Hard kill → resume (`hard_kill_recovery`) | PASS | a run killed with no cleanup is detected as crashed once its heartbeat is stale; its in-flight call is closed as failed and settled at the estimate; resume finishes the queue without re-sending any completed ID (checker resume rules pass) |
| Real failures so far (`real_transient_failures`) | PASS | record every real failed call so far (no fake data); each was settled at its estimate when billing was unknown |
| Synthetic records excluded (`synthetic_exclusion`) | PASS | synthetic rows (SYNTH- IDs) exist only in their own DBs under state/m7_*; none in state/pipeline.db, outputs/ or grading/ (so none in business aggregates or the export) |
| Prompt injection (real models) (`injection_real`) | recorded | record what actually happened: whether any label follows the injected instruction instead of the complaint; no output for an unsent review; quotes are exact substrings |
